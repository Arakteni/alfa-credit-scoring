# Скор-карта (балльная модель)

> Синтетические данные; скор-карта демонстрирует методологию и не переносится на реальный портфель.

Версия: `v1.0.0-woe-logit`. Шкала: **600 баллов = PD 5%**, удвоение шансов каждые **50 баллов**; баллы выше — риск ниже; итог ограничен диапазоном 300–900.
Базовая константа: **544.1**. Итоговый балл = константа + сумма баллов по корзинам признаков.

Колонка «вклад vs средний» = баллы корзины − средневзвешенные баллы признака по обучающей выборке (положительный — лучше среднего заёмщика).
