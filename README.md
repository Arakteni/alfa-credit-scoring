# Скоринг малого бизнеса: DS-часть

Хакатон «Умный кредитный кабинет предпринимателя» (Альфа-Банк × Changellenge). Модель оценивает вероятность дефолта (PD) компании или ИП и отдаёт рекомендацию: рейтинг, лимит, ставку, срок, флаги политики и причины оценки.

> **Все данные синтетические.** Они сгенерированы командой, не относятся к реальным лицам и организациям, а метрики не переносятся на реальный портфель.
> Скоринг не принимает кредитное решение: одобрение или отказ остаётся за credit-core, пороги в модель не зашиты.

## Что нужно

- Python **3.12** (проверено на 3.12.10), `make`, Linux или macOS (на Windows - WSL).
- Версии библиотек зафиксированы в `risk-scoring/requirements-ds.lock.txt`. Они важны: модель хранится в `joblib`, и с другими версиями sklearn она может не загрузиться.

## Быстрый старт (проверка за ~1 минуту)

Из корня репозитория:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r risk-scoring/requirements-ds.lock.txt

make data    # ~3 с: генерирует синтетические данные в data/generated/ (их нет в репозитории)
make test    # ~10 с: 27 тестов, ожидаемо "27 passed"
```

`make data` обязателен перед `make test`: тесты читают `data/generated/applications_raw.csv`, а CSV не лежат в репозитории (они побайтово воспроизводятся из seed 42, контрольные суммы - в `data/generated/manifest.json`). Без этого шага 19 тестов из 27 упадут с ошибкой "файл не найден".

## Полный пересчёт с нуля (необязательно, ~2 минуты)

Ноутбуки `notebooks/01…08` пересоздают признаки, модели, скор-карту, метрики, графики и документацию. Для запуска нужен `nbconvert`, которого нет в lock-файле:

```bash
pip install nbconvert==7.16.6
make all     # = make train + make report + make test
```

Метрики после пересчёта совпадают с `docs/ml/metrics.json`.

Ноутбуки можно открывать и запускать по одной ячейке: `jupyter lab notebooks/`. Порядок: 01 данные, 02 признаки, 03 модели, 04 скор-карта и рейтинги, 05 валидация, 06 движок и тесты, 07 демо-кейсы и фикстуры, 08 документация. Нагрузку на процессор можно ограничить: `export OMP_NUM_THREADS=2`.

## Как оценить одну компанию

Основная модель - WOE-логрегрессия с калибровкой Платта (`risk-scoring/models/risk_model_woe_logit_v1.joblib`). Запуск из корня репозитория (после `make data`):

```python
import sys; sys.path[:0] = ["risk-scoring", "."]
import pandas as pd
from riskscore.engine import ScoringEngine

eng = ScoringEngine("risk-scoring/models")

# демо-компании: плоский формат, 174 колонки (профиль, 8 кварталов отчётности,
# 12 месяцев оборотов, данные БКИ и ФНС, параметры заявки)
raw = pd.read_csv("data/fixtures/companies_flat.csv", dtype={"inn": str, "ogrn": str})

print(eng.score_one(raw.iloc[0].to_dict()))   # одна компания -> dict
results = eng.score_frame(raw)                # пачка -> список dict
```

Ответ - обычный словарь Python (файл сам не создаётся):

| Поле | Что это |
|---|---|
| `pd` | вероятность дефолта (калиброванная) |
| `riskScore` | скор по скор-карте |
| `ratingGrade`, `riskSegment` | рейтинг (AAA…D) и сегмент риска |
| `recommendedLimit`, `recommendedRate`, `maxTermMonths` | рекомендованные условия |
| `policyFlags` | флаги политики с важностью CRITICAL / WARNING / INFO |
| `reasons` | главные факторы оценки с пояснением на русском |
| `warnings` | чего не хватило во входе, какие признаки пришлось обрезать |
| `modelVersion`, `calculatedAt`, `latencyMs` | служебные поля |

Дополнительно: `eng.suggest_conditions(row)` подбирает сумму и срок, при которых лимит покрывает запрос, а `eng.model_info()` отдаёт версию, список признаков и метрики.

## Структура

```
data/               генератор синтетики (generate.py, seed 42) и фикстуры для моков и БД (fixtures/)
notebooks/          8 ноутбуков: данные -> признаки -> модели -> скор-карта -> валидация -> движок -> кейсы -> документация
risk-scoring/
  riskscore/        код: признаки, WOE, модели, метрики, ScoringEngine (без него модель не загрузится)
  models/           обученные артефакты основной модели, скор-карта, шкала рейтингов
  tests/            27 тестов
docs/ml/            карточка и отчёт модели, словарь признаков, шкала рейтингов, скор-карта, описание генерации данных
docs/test-data.md   демо-кейсы: ИНН -> ожидаемое поведение
```
